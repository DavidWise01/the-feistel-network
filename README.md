# THE FEISTEL NETWORK

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **KRYPTOS**.

THE FEISTEL NETWORK &mdash; a member of [[kryptos]]. Build an invertible block cipher from ANY round function F: each round L&prime;=R, R&prime;=L&oplus;F(R,K&#7522;). Since XOR self-inverts and one half passes through, decryption is the same structure with reversed keys &mdash; so F can be as nonlinear as you like while reversibility is guaranteed. The skeleton of DES and Blowfish. &#9670; LIT: a fail-loud check throws unless decrypt(encrypt(m))=m for a non-invertible F. &#9650; AMBER: toy 8-bit F / 4 rounds; real ciphers need wide blocks and many rounds vs differential/linear cryptanalysis.
